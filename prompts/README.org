* Prompts

Every prompt a lab has a person type into a model, one file each, named for
the lab and for what the prompt is for. The text is the lab's, from
=neo4j-partners/hands-on-lab-neo4j-and-google= (Apache 2.0), unchanged. A
file holds the prompt and nothing else, so code can read it and a diff shows
when one was edited.

Where a lab has a query and not a prompt, it is in =labs/= as Cypher.

Naming: =lab-NN-= then, when a lab has several, a two-digit order, then what
the prompt does in a few words. A prompt of our own, not from a lab, drops
the lab number and says so on its first row here.

When a prompt is run, its row gets the date and where the answer was
recorded. A changed prompt is a new file, not an edit, when the old answer
is kept anywhere.
