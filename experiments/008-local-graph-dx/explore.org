* Clojure blocks: ob-clojure through CIDER

=ob-clojure= ships with Org. Its backend on this machine defaults to
babashka, which has no Neo4j driver, so the file's header sets
=:backend cider=.

#+begin_src clojure
(session/q "MATCH (m:Manager)-[o:OWNS]->(c:Company {companyName: $name})
            RETURN m.managerName AS manager, o.shares AS shares

* Cypher blocks, through the same REPL

=ob-cypher-cider.el= in this directory is thirty lines: it hands a cypher
block's body to =local-graph.session/org-table= over nREPL. Evaluate this
once per Emacs session:

#+name: load-ob-cypher-cider
#+begin_src emacs-lisp :results silent
(load-file (expand-file-name "ob-cypher-cider.el" default-directory))
#+end_src

#+name: shared-holdings
#+begin_src cypher
MATCH (a:Manager)-[:OWNS]->(c:Company)<-[:OWNS]-(b:Manager)
WHERE a.managerName < b.managerName

* sh blocks: cypher-shell from Maven Central

=bin/cypher-shell= runs the =org.neo4j/cypher-shell= jar on the JVM already
here; nothing is installed. It connects over Bolt to the server the REPL
started, so it works while the REPL is up. About a second a call, nearly all of
it the JVM starting.

#+name: constraints
#+begin_src sh
bin/cypher-shell -a bolt://localhost:7688 --format plain \
  'SHOW CONSTRAINTS YIELD name, type, labelsOrTypes, properties'
#+end_src

#+RESULTS: constraints
