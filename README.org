** Tooling

=gmake help= lists the targets. =gmake agenda= and =gmake todos= read the
checklist above. =gmake .env= starts a credentials file from =.env.template=;
=gmake ping= and =gmake cypher FILE=...= run against the instance it names.
=gmake data/<name>= fetches one of the workshop's datasets into =data/=, once.
The labs themselves need only a browser. The queries run go in =labs/=, the
prompts typed into a model go in =prompts/=, one named file each, and what
bit goes in =.meta/findings.md=.

The same and more in Clojure, in =src/workshop/=: =workshop.neo4j= over the
official Java driver, =workshop.gcp= over Google's Cloud Storage client.
=bb tasks= lists the commands (=bb ping=, =bb counts=, =bb cypher FILE=,
=bb datasets=, =bb peek OBJECT=, =bb test=). In Emacs, =cider-jack-in= opens a
REPL in =dev/user.clj=, where =(q "MATCH ...")= runs a statement and returns
rows as maps.

=bb form13= explores Lab 4's day file locally, with no database: =summary=,
=top=, =degree=, =variants=, =odd=; =verify= compares the database with the
file and =load= runs the keyed load only when they differ. =dev/explore.clj=
is a page of =(comment ...)= blocks to evaluate one form at a time, lab by
lab; =bb repl= starts the nREPL for it.

=experiments/= holds numbered experiments, each with a hypothesis, a gate
and a dated log of what was tried:

- =001-msa-similarity=: the Dataproc notebook's similarity graph in Python, then in Clojure as =bb msa=
- =002-form13-rdf=: the Form 13 data as RDF triples with Jena and SPARQL
- =003-form13-datalog=: as datoms in DataScript and triples in Asami
- =004-form13-core-logic=: as core.logic facts
- =005-graph-builder-api=: Lab 6's result through the LLM Graph Builder's API
- =006-structured-extraction=: the same extraction with a local model held to a JSON schema; the gate was not passed
- =007-query-ui-cljs=: a ClojureScript replica of the Query tool, and Bombadil properties run against it
- =008-local-graph-dx=: Lab 4's load on an embedded Neo4j, a container and Memgraph, before any cloud
- =009-local-agent=: Lab 9's agent as a small local model that only chooses a template; passed by one model of four
- =010-papers-dataset=: a bibliography's arXiv papers as a graph; authors and citations passed, the model's layer did not

=workshop.labs= is each lab as a function returning data: =(run-all)= in a
REPL, =bb labs= in a shell, three ok, one skipped and six blocked on what they need.
=workshop.audit= (=bb audit=) is the same for what the notes claim.
=dev/labs_explore.clj= walks both, one form at a time. Neither writes.

=bb status= runs every connection check once: the instance, the dataset
bucket, the lab browser, the lab's remaining time, the environment, the
checklist. =bb dashboard= serves the same as a page on
=http://127.0.0.1:8377/= that reloads itself. Beside it, =/data= asks five
questions of the graph and =/traces= shows what every statement and check
cost. =WORKSHOP_ENV=local-graph.env= points all of it at the local server.
